# Screenshot provenance

The PNG files in this directory are unmodified crops of genuine Kaeru windows
and tray menus captured from the installed 0.2.0-3 application on the tested
Pop!_OS 22.04 / GNOME 42 / X11 session. They are provided for the public README
only; no mockups or generated screenshots are used.

- `main-window.png` — Keep Awake page, dark theme
- `tray-menu.png` — compact tray menu with `Kaeru: ON`
- `tray-durations.png` — expanded duration submenu including `Custom…`
- `about.png` — About page with the original frog artwork

The frog artwork itself is referenced directly from `resources/icons/frog/png/`
and is never regenerated or recolored here.
