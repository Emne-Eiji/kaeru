# ADR-008 — Official Frog Icon Identity and Tray State Mapping

**Status:** accepted (2026-11-16) · **Supersedes:** the original SVG icon set of WP-02
**Context:** Kaeru's tray/launcher identity (spec §8.4, uiux-design §10)

## Decision

1. **Official artwork.** The frog icon set supplied by Emne (approved as Kaeru's
   visual identity) replaces the WP-02 placeholder icons. Three expressions:
   `awake.svg` (eyes open, wide smile), `focused.svg` (heavy angled lids,
   lowered pupil), `sleep.svg` (thick curved closed lids). Original artwork is
   preserved byte-identical in `resources/icons/frog/` (SVG) and
   `resources/icons/frog/png/` (supplied raster variants 16–512 px);
   `frog-tray-icons.svg` is a *preview composition* of the three expressions
   (1500×540 canvas), not a runtime sprite sheet — it is kept for documentation
   only. `generate_icons.py` is the original generator, kept for provenance;
   it is never run at build time.
2. **Launcher/brand icon.** `io.github.kaeru.Kaeru.svg` (hicolor scalable) =
   the **awake** expression — recognizable and state-neutral for a launcher.
   PNG fallbacks at hicolor sizes 16–256 for desktops without SVG support.
3. **Tray expressions and precedence.** The tray uses the same three
   expressions. Because keep-awake inhibition and focus sessions can coexist
   and three expressions cannot encode every combination, the mapping is:

   | App state (evaluated in order) | Icon | Tooltip summary |
   |---|---|---|
   | Pause All / Keep Awake module off | Sleep | `paused (Pause All)` / inactive |
   | Keep awake Active or PartiallyActive | **Awake** | `keep awake active` (+ limitation if partial) |
   | Focus interval running (Work/Short/Long) | **Focused** | `focus running` (+ phase, remaining) |
   | Activating (pending, not yet active) | Sleep | `activating…` (never the awake face) |
   | Keep awake Failed / PermissionDenied | Sleep | `keep awake failed/denied` + error detail |
   | Neither active | Sleep | `inactive` |

   **Safety-first precedence:** when both keep-awake and focus are active the
   *awake* expression wins the icon (the tray's primary promise is sleep
   protection); the tooltip always states both facts ("keep awake active ·
   … · Countdown (59s left)"), so focus is never hidden. The sleeping
   expression means **Kaeru is inactive** — never that the computer is
   sleeping; the tooltip always names the actual state. Recording a work-log
    session does not change the icon; it is appended to the tooltip.
4. **No redrawing.** The frog is never recolored, restyled or regenerated by
   the application. Icon selection is a pure function
   (`core/TrayState.h::decideTrayPresentation`) with unit tests
   (`test_traystate`).
5. **Resource path fix.** `qt_add_resources(... PREFIX "/" BASE resources
   FILES resources/icons/frog/*.svg)` produces the aliases `:/icons/frog/*.svg`
   that `Icons.cpp` loads. (The WP-02 setup had a broken alias — icons never
   loaded from resources; this ADR records the corrected mechanism.)

## 0.2.0 amendment — PNG runtime assets

Qt 6.2's SVG renderer mis-paints `focused.svg` (clip-path on the eye lids
produces a black face), so the runtime `QIcon` path no longer renders SVG.
The embedded resource set now contains the supplied PNG variants
(`:/icons/frog/png/{awake,focused,sleep}-{16…256}.png`) and `Icons.cpp`
selects those sizes; the installed hicolor SVGs remain for desktop menus and
launchers. This is an asset-selection change, not a redraw: the original
artwork and palette are unchanged, and `test_icons` guards the focused
palette. The decision’s identity, precedence and tooltip rules are unchanged.

## Consequences

- The frog is Kaeru's recognizable identity in the tray, launcher, window and
  About view; functional icons (navigation, actions) remain conventional.
- A three-expression set cannot show "focus running while keep-awake is
   partial/failed" distinctly — the tooltip carries the nuance (documented
   limitation).
- Desks that desaturate tray icons (e.g. the `desaturated-tray-icons` GNOME
   extension) will render the frog in greyscale; the shape remains legible
   (verified on the dev machine, which has that extension enabled).
